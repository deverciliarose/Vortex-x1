# VORTEX X1

O VORTEX X1 é um projeto de apresentação interativa de produto, desenvolvido com React. A aplicação permite que o usuário visualize um modelo de tênis e altere sua cor de forma dinâmica, proporcionando uma experiência visual simples e intuitiva.

## Funcionalidades

Visualização do produto.

Seleção de diferentes cores (preto, vermelho e branco).

Atualização dinâmica da imagem conforme a cor selecionada.

Interface moderna e responsiva.

Navegação simples e intuitiva.

## Como executar o projeto 
Clone o repositório
git clone https://github.com/deverciliarose/Vortex-x1.git

Entre na pasta 
cd vortex-x1

Instale as dependências 
npm install

Execute o projeta 
npm run dev
